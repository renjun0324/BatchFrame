# UI 分组纠偏

## 一级工具不变

编辑器底部仍只有：

```text
模板 · 画布 · 内框 · 图片
```

不得增加“胶片”“胶片模式”“相机模式”或“模板库”作为并列工具。

## 内框面板

内框面板内按两个视觉组展示：

```text
基础内框
  无内框
  经典细黑边
  全幅扫描边
  乳剂破损边

片基内框
  35mm 完整片基
  极简胶片边码
  120 中画幅片基
  16mm 电影片基
  接触印样片基
```

每张卡片都属于同一个内框选择器，只是用分组标签解释它的结构复杂度。卡片局部要包含 `frameRect` 与 `apertureRect` 的关系、齿孔/边码/标记等真实辨识点。

## 条件参数

| 内框类型 | 面板控件 |
|---|---|
| 经典细黑边 | 内框宽度、内框颜色 |
| 全幅扫描边/乳剂破损边 | 边框版本、内框宽度 |
| 35mm 完整片基 | 片基尺寸（紧凑/标准）、齿孔开关、边码开关、帧号自动/关闭 |
| 极简胶片边码 | 片基尺寸、边码开关、帧号自动/关闭、角标开关 |
| 120 中画幅片基 | 片基尺寸、边码、帧号 |
| 16mm 电影片基 | 片基尺寸、齿孔开关、帧号 |
| 接触印样片基 | 片基尺寸、档案线、帧号 |

片基尺寸不是四边统一像素宽度；它是该内框的结构预设，会改变 `frameRect` 与 `apertureRect` 的相对比例。

## 外层留白控制

外层留白仍在“画布”面板中调整。用户调整留白时，内框类型和片基结构不变，只重新计算 `innerAvailableRect` 后将 `frameRect` 放入其中。
