# 固定编辑工作台与胶片内框回归清单

正式入口：`pages/frame/frame`。本清单需要在微信开发者工具、iPhone 和至少一台 Android 真机执行；当前仓库环境无法启动微信 Linux 开发者工具，因此未在本环境声称真机通过。

## 固定工作台

1. 导入一张横图，确认图片立即显示，不需要点击其他控件。
2. 导入一张竖图，确认图片立即显示，预览完整且不溢出。
3. 导入九张横竖混合图片，确认缩略图横向滚动、点击切换立即更新。
4. 页面本身不做上下滚动；向下修改设置时主预览仍在屏幕内。
5. 在“画布”中切换 1:1、4:5、3:4、2:3、9:16、16:9，确认画布完整显示。
6. 在“内框”中切换风格、宽度和强度，确认预览实时更新且工作台不跳动。
7. 在“图片”中修改缩放，确认预览持续可见；未实现的位置控件不应出现。
8. 设置内容较多时只滚动设置面板，工具栏和底部批量导出按钮位置稳定。
9. 收起/展开设置面板，确认预览仍保留可见区域并适配底部安全区。
10. 快速切换缩略图，确认旧图片异步加载结果不会覆盖当前图片。

## 胶片内框

11. 默认经典细黑边保持四边笔直、宽度一致、接近纯黑。
12. 暗房扫描边在正常手机尺寸可辨认：边缘连续、略有凹口和四边差异，不呈现明显锯齿。
13. 粗粝显影边在正常手机尺寸可辨认：有干刷、侵蚀、局部堆积和少量碎点，但不遮挡照片主体。
14. 视觉边框卡片能显示真实风格差异，不只是同一张缩略图换文字。
15. 同一照片反复切换回来，边缘变体和缺口位置不改变。
16. 预览与导出使用相同边缘变体；对比左上角、右下角和长边局部。
17. 批量导出九张照片，确认整体风格统一、每张 seed 稳定。
18. 关闭外层背景后仍输出 PNG；修改外层背景不改变内框。
19. 后台内容安全检测仍不阻塞导入和编辑，导出前策略保持不变。
20. 离开页面后无残留绘制定时器、mask 图片缓存或异步绘制任务。

## 自动检查

```bash
npm test
python3 tools/generate-frame-mask-assets.py
python3 tools/generate-frame-contact-sheet.py
```

`docs/frame-style-review/contact-sheet.png` 是本地视觉对比证据，包含完整构图、左上角和右下角放大区域。真机视觉与微信 Canvas 资源加载行为需在目标工具/设备上逐项执行并记录结果。
