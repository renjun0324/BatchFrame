# BatchFrame V3 胶片边框视觉规范（设计阶段）

本文件是下一轮生产接入前的视觉契约。当前所有样张均为设计资产，不会自动替换 `core/` 的生产渲染器。

## 共同约束

- 外层画布、照片内容和内层胶片结构分离；不改变照片颜色。
- 所有编号、箭头、圆点和代码均为项目自行生成的通用标记，不代表任何胶片品牌。
- 边框必须在 1:1、4:5、3:4、2:3、9:16、16:9 下保持结构比例；齿孔使用重复单元而非拉伸整张 PNG。
- 每张照片使用稳定 seed 选择变体；预览和导出共享同一结构描述。
- 设计阶段样张使用仓库示例照片局部，未接入运行时。

## 结构差异

- `full-frame-scan` 使用连续的低频轮廓，不能通过 `roughness` 直接变成粗粝风格。
- `film-gate` 使用四边不同厚度和角部压框块，不共享扫描边路径。
- `negative-35mm` 与 `cine-16mm` 的主要结构是规则重复齿孔；区别在齿孔尺寸、密度和边位置。
- `medium-format-120` 没有 35mm 齿孔，使用宽片基和少量通用记号。
- `contact-sheet` 的识别点是底部档案线和帧号，不是噪声。
- `emulsion-damage` 使用局部侵蚀区域和稀疏碎屑，主体安全区必须保持干净。

## UI 卡片

V3 卡片最低可视区域为 116–140px 宽、72–96px 高。卡片应来自未来统一 renderer 的低分辨率输出，至少包含一个完整角部和两条相邻边。设计阶段使用 `tools/design-v3/generate-design-v3.py` 生成的真实结构样张；下一轮接入时应将同一风格定义映射到 `core/innerFrameStyles.js` 与新的专用 renderer。
