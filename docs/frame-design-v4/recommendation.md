# 第一批候选建议（等待人工确认）

这不是最终定稿。建议先用六个候选进行手机盲评，其他候选暂不接入生产。

| 优先级 | 候选 | 建议理由 | 风险/待确认 |
|---|---|---|---|
| P0 | `a1-mount-line` 经典装裱线 | 最符合“大外层背景 + 小黑线”的核心定位，批量使用最稳定 | 需要确认是否与现有 `clean-black` 视觉保持兼容 |
| P0 | `a2-scan-edge-b` 全幅扫描 B | 比 A 版本更容易在手机上看见单侧片夹痕，但仍不会遮挡照片 | 不能让凹口看起来像随机锯齿 |
| P0 | `a3-film-gate` 片门压框 | 左/下方向性和角部堆积能与扫描边形成结构差异 | 宽片基可能不适合 9:16，需要比例回归 |
| P1 | `a4-emulsion-a` 乳剂破损 A | 有完整破损区而非噪点，作为材料风格的最低风险版本 | 需要确认组图中是否仍然克制 |
| P1 | `b1-negative-35mm` 35mm 负片 | 齿孔节奏和帧号在手机上最容易识别，系列 B 的明确锚点 | 片基不能喧宾夺主，编号必须保持通用 |
| P1 | `b2-medium-format-120` 120 中画幅 | 宽 rebate/单侧标记与 35mm 形成真实结构差异，适合方图和 4:5 | 需要明确不推荐比例的降级策略 |

## 暂缓

- `a2-scan-edge-a`：太接近经典细黑线，盲评中可能合并。
- `a2-scan-edge-c`：识别强，但边缘侵入风险高。
- `a4-emulsion-b/c`：适合作为后续版本，不宜第一批同时出现。
- `b3-cine-16mm`：方向明确，但需要单独验证 16:9 和小齿孔的真机可读性。
- `b4-contact-sheet`：档案感强，适合批量创作者，但与 35mm/120 的用途重叠，需要产品场景确认。

人工确认前，以上候选不会写入 `miniprogram/core/innerFrameStyles.js`，也不会进入真机选择器。
