# 候选实现建议（仅设计阶段）

本文件不修改生产 renderer，只为人工选定后提供接入边界。

| 候选 | 建议实现 | 本地资产 | 不应共用的 renderer | 比例适配与回退 | 粗略资源成本 |
|---|---|---|---|---|---|
| A1 经典装裱线 | 纯 Canvas 硬边几何 | 无 | 与所有材料边分开 | 直接矩形；未知比例仍保持窗口 | 极低 |
| A2 全幅扫描 A/B/C | 角部素材 + 边缘分片平铺；每个版本固定轮廓 | 8 分片 × 2–3 变体 | 不与乳剂侵蚀共用噪声函数 | 归一化边缘轮廓，角部不跨边平滑 | 低至中 |
| A3 片门压框 | 纯 Canvas 多边形 + 固定角部堆积 | 无或 4 个小角部纹理 | 不与扫描边共用路径 | 按左右/上下厚度比例缩放 | 极低 |
| A4 乳剂 A/B/C | 角部素材 + 边缘分片 + 稀疏程序碎屑 | 8 分片 × 2–3 变体 | 不与全幅扫描共用同一 profile | 保持矩形安全区；碎屑只在边缘 | 中 |
| B1 35mm 负片 | 纯 Canvas 重复齿孔 + 通用矢量标记 | 无；必要时数字图集 | 不与 16mm 共用 pitch/孔尺寸 | 按长边等比例，横竖方向固定片基轴 | 极低 |
| B2 120 中画幅 | 纯 Canvas 宽 rebate + 单侧标记 | 无 | 不与 35mm 共用齿孔 renderer | 优先 1:1/4:5/3:4；不推荐比例仍保留矩形窗口 | 极低 |
| B3 16mm 电影胶片 | 纯 Canvas 小齿孔 + 单侧编号 | 无 | 不与 35mm 共用重复单元 | 16:9 优先；其他比例只调整边带，不拉伸孔 | 极低 |
| B4 接触印样 | 纯 Canvas 档案线 + 编号 + 裁切标记 | 无 | 不与 perforated-film 共用 | 3:4/4:5/1:1 优先，边码放在片基 | 极低 |

## 一致性要求

1. 预览和导出必须调用同一个候选 renderer；设计卡片只使用相同候选的低分辨率静态产物。
2. 所有随机或变体选择必须由图片稳定 ID 和候选版本决定，不能每次重绘变化。
3. 资源缺失时只回退到 `clean-black`，不能把缺失误判为无内框。
4. 本轮设计资产全部位于 `docs/frame-design-v4/`，接入时再评估是否需要复制小型运行资源。
5. 第一批推荐最多六个，优先选择能在手机宽度下靠结构而不是宽度区分的候选。
