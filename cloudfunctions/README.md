# 云函数部署说明

## 内容安全检测功能

本项目已接入微信内容安全检测API，用于检测用户上传的图片是否包含违规内容。

### 部署步骤

#### 1. 开通云开发

1. 在微信开发者工具中，点击顶部菜单 `云开发` 按钮
2. 如果是第一次使用，需要开通云开发服务
3. 创建一个云开发环境（免费版即可）
4. 记下环境ID（可选，不填会使用默认环境）

#### 2. 配置环境ID（可选）

如果你创建了多个云环境，需要在 `app.js` 中指定环境ID：

```javascript
wx.cloud.init({
  env: '你的环境ID', // 填入云开发控制台查看到的环境ID
  traceUser: true,
})
```

#### 3. 上传云函数

1. 在微信开发者工具中，找到左侧 `cloudfunctions` 目录
2. 右键点击 `checkImage` 文件夹
3. 选择 `上传并部署：云端安装依赖`
4. 等待上传完成

#### 4. 配置云函数权限

云函数已经在 `config.json` 中配置了所需权限：
- `security.imgSecCheck` - 图片内容安全检测

微信会自动识别并授予权限。

#### 5. 测试

1. 重新编译小程序
2. 选择图片时，会自动调用内容安全检测
3. 检查控制台日志，确认云函数调用成功

### 功能说明

- **自动检测**：用户选择图片后，自动进行内容安全检测
- **违规过滤**：检测到违规图片会自动过滤，只保留安全图片
- **友好提示**：检测失败时不影响用户使用，会给出友好提示
- **批量处理**：支持批量检测多张图片

### 注意事项

1. **云开发配额**：免费版云开发有配额限制，建议升级为付费版
2. **检测速度**：图片需要先上传到云存储再检测，速度取决于网络和图片大小
3. **成本控制**：每次检测都会消耗云函数调用次数和云存储空间，建议合理使用

### 常见问题

**Q: 云函数调用失败？**
A: 检查是否已开通云开发，是否已上传并部署云函数

**Q: 检测一直提示异常？**
A: 检查云开发环境是否正常，检查控制台日志查看详细错误信息

**Q: 能否跳过检测？**
A: 不建议跳过，这是微信平台的合规要求。检测失败时系统会自动降级处理
